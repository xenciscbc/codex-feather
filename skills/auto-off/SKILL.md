# Auto off

Set review mode to `off` using [the shared procedure](../setup/references/auto-review.md). No argument means this conversation only. Arguments select scope, never a different mode. Clarify a conflicting request. Keep any existing logical plan's automatic review count and findings. Explicit plan-review requests still apply.
