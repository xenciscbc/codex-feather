# Handoff save

Read [the shared handoff skill](../handoff/SKILL.md) and follow its save workflow and write discipline using the Python tool. This invocation requests saving progress; no operation argument or additional save confirmation is needed.

Use the named work or the work clearly established by the conversation. If the work is unclear, ask which work to save. Reuse its existing record, or create one for new work. Record observed progress and verification; identify unverified claims. Saving alone does not authorize executing the recorded next step.

Read back the saved result and report its path and status. If the whole work is already complete, follow the shared completion and archival procedure.
