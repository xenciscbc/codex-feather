# 08: 完整互動安裝體驗

Type: task
Status: claimed
Blocked by: 05, 07

**What to build:** 使用者直接啟動安裝器即可透過引導完成檢查、安裝、更新、移除或明確遷移。選單與完整參數模式使用一致的操作規則與結果。

- [ ] 無參數啟動提供互動引導，依操作選擇元件、元件範圍、目標及入口位置，套用前呈現實際變更摘要。
- [ ] 所有既有操作都可從引導完成；只询問該操作缺少的資訊，完整參數命令仍直接執行，不因加入互動模式而多出確認。
- [ ] 入口可選不加入、專案或使用者，與元件範圍獨立；重複元件提供沿用或明確遷移，不默認覆寫。
- [ ] 手動修改衝突可明確選擇保留或替換，替換前保存備份；保留、取消或預覽不留下本次部分部署。
- [ ] 缺少 Codex、無法解析目標、權限不足、寫入失敗及復原失敗均顯示可採取的下一步，不宣稱未完成的操作成功。
- [ ] 在隔離環境以相同選項分別執行互動及完整參數模式，比對外部結果、檔案與設定；不只比對提示文字或內部呼叫順序。
- [ ] Windows x64 與 Linux x64 最終完整發行包可在不另裝 Python 的環境執行；各操作、元件、範圍與入口組合具有可追溯的整合驗收結果。
- [ ] 使用說明涵蓋下載完整包、互動及命令使用、預覽、更新、移除、遷移、衝突與復原，說明不代裝 Codex及 Windows／WSL 環境差異。
- [ ] 發行驗收分開記錄檔案操作與原生 Codex 載入證據，說明實際驗證的 Linux 系統相容性及 Codex 環境；未驗證項目不標示為通過。
