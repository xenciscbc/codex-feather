- [x] 支援專案與使用者範圍，預設仍為專案；檢查與操作摘要列出解析後的實際目標，不根據安裝器所在位置猜測範圍。
- [x] 遵循 Codex home 與使用者 skill home 各自的發現規則；自訂 Codex home 不會錯誤地連帶改寫 skill home。
- [x] Windows 原生與 Linux／WSL 使用各自環境的目標，不假設 Windows 與 WSL 共用安裝；在隔離 home 驗收，不動用真實使用者設定。
- [x] 檢查可見的使用者及專案層同名元件；發現重複時提示沿用既有安裝，不自行新增副本，也不假設專案元件會覆蓋使用者元件。
