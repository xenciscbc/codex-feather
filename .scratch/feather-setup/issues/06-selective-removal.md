# 06: 選擇性移除

Type: task
Status: resolved
Blocked by: 04

**What to build:** 使用者可移除所選範圍內由安裝器管理的 Feather 元件與入口，同時保留手動修改、其他設定及所有交接資料。

- [x] 依安裝紀錄列出可移除元件與相關受管理項目，只處理使用者指定範圍及選項，預覽不刪除任何內容。
- [x] 只移除所選元件對應的入口內容，保留仍在使用的其他元件指引、區塊外文字與無關設定。
- [x] 不刪除交接檔、交接歷史、來源不明的同名內容或其他工具資料；不因資料夾包含部分受管理檔案就整個遞迴刪除。
- [x] 移除前比對上次安裝內容。手動修改時保留並列出衝突，明確處理前不刪除；非互動衝突回傳非成功結果。
- [x] 已明確選擇處理的修改內容在移除前可由備份取回；未選元件與其安裝紀錄保持完整。
- [x] 無衝突完整參數直接執行；已移除項目再次檢查或移除時如實回報，不誤刪後來新增的無關內容。
- [x] 多項移除途中失敗時還原本次刪除及紀錄變更；復原失敗如實列出剩餘狀態與備份位置。
- [x] 在兩個支援平台以隔離情境驗證單元件及整套移除、混合入口、手動修改、交接資料保留、無關檔案保留与失敗復原。

## Comments

與 05 可分別開工。移除有自身的衝突與備份驗收，不依賴更新功能完成。


## Answer

已交付依紀錄移除所選元件與入口；手動修改預設停止，明確替換後才備份並移除。不遞迴刪除元件目錄，保留交接與歷史、額外檔案、未選元件與設定；重跑不刪除後來新增的非受管理內容。入口採共用參照，最後使用者移除後才清理。Windows／Linux 各 4 項移除整合情境全數通過，涵蓋兩個範圍、跨範圍入口、共用入口、備份與移除中途故障還原。型別檢查 11 個來源檔通過；最終發行包矩陣接續於 08 重驗。
