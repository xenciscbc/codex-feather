# 01: 安裝工具並列出交接清單

Type: task
Status: resolved
Blocked by: None
Parent: [Feather 交接工具規格](../spec.md)

**What to build:** 使用者安裝或更新交接 skill 後，可用隨附 Python 工具列出正常格式的交接清單並讀取指定工作；缺少合適 Python 時由 Agent 詢問是否協助安裝。

**涵蓋使用者故事：** 1–9、22、38–42。

- [x] Python 3.11+ 工具只使用標準函式庫，隨 skill 安裝、更新及移除；移除保留既有交接資料，安裝器自身不需 Python 的條件仍成立。
- [x] 提供公開清單與指定讀取操作；正常格式工作顯示名稱、相對位置、狀態、進度及工作更新時間，同名不同檔案分別列出。
- [x] 清單從原交接即時產生，不建立索引或快取；包含進行中、受阻及完成待歸檔工作，排除共同歷史與封存。
- [x] 指定讀取回傳完整交接及可供後續更新使用的內容版本依據；清單摘要不能當成接續授權。
- [x] 正確解析專案根目錄、直接工作檔與實際路徑範圍，拒絕越界或不安全別名；正常的空清單與來源不存在可區分。
- [x] 所有查詢保持唯讀，不改交接、Git 規則或執行記錄中的下一步；未知格式至少明確回報未確認，不能錯報完整，進一步相容由 02 完成。
- [x] 缺少或版本不符的 Python 時，skill 詢問是否需要協助安裝；使用者未同意、拒絕或安裝失敗時不自動安裝或繞過工具寫入，仍可唯讀查閱原檔。
- [x] 同步工具使用指引及安裝檢查；在隔離環境透過公開安裝與工具入口驗收正常讀取、空清單、部署生命週期與範圍保護。Windows／Linux 結果分別記錄，未驗證項目明列。
- [x] Agent 的安裝詢問與唯讀操作以隔離行為證據核對；離線程式結果與實際 Agent 證據分開標示。

**交付邊界：** 本票包含對應的工具行為、skill／使用指引及公開入口驗收；不以只建立內部模組或手寫預期產物代替完整操作。只接管本票已交付的操作，尚未移交的功能保留既有流程；全部票據完成後，規格內的正常受管理寫入均走同一工具。缺少實際平台或 Agent 證據時明列未確認，不把離線產物通過當作行為已通過。


## Answer

完成 Python 公開清單／指定讀取、摘要與版本依據、安裝器 Python 環境診斷及 skill 指引。公開工具 3 項測試與安裝檢查 5 項測試在 Windows 通過；工具型別檢查通過。安裝 payload 沿用整個 skill 複製；Linux 及獨立 Agent 操作證據將於整體驗收記錄，尚未確認。

整體驗收：[工具驗收記錄](../../../docs/handoff-tool-validation.md)。Windows 全套 145 項通過（略過 2）；WSL 新增 31 項通過（略過 3 項 Windows 分享限制測試）。Agent 行為與未確認項目分開記錄，不將離線通過視為全部原生行為已驗證。
