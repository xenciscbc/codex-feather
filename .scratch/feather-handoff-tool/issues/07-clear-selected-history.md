# 07: 清除指定歷史

Type: task
Status: resolved
Blocked by: 04, 06
Parent: [Feather 交接工具規格](../spec.md)

**What to build:** 使用者明確選取歷史後，工具只移除授權的紀錄並保留其他內容；歧義、版本衝突或失敗時不擴大操作範圍。

**涵蓋使用者故事：** 22、34、37、38、42。

- [x] 使用者清楚選取後可直接清除；同名完成身份、範圍或紀錄界線有歧義時先釐清，保留資料。
- [x] 預設只清共同歷史，封存需明確納入；清除全部共同歷史仍保留封存及工作檔。
- [x] 寫入前核對讀取版本及完整選取，過時版本停止並交回重讀；共同歷史操作由單一寫入者依序協調，不增加鎖定。
- [x] 僅移除選定完整紀錄，保留未選定內容；完成後讀回驗證實際移除及其餘資料保留。
- [x] 失敗回報實際狀態與可恢復資料；重試重新核對原選取，不因原項目已不存在而改刪其他同名紀錄。
- [x] 不能刪除未完成或完成待歸檔的原交接，也不能把普通查閱解讀為清除授權。
- [x] 同步 skill 授權選取、衝突及失敗指引；公開操作驗收部分／全部清除、封存範圍、歧義、版本衝突及故障恢復，核對未選定資料完整保留。

**交付邊界：** 本票包含對應的工具行為、skill／使用指引及公開入口驗收；不以只建立內部模組或手寫預期產物代替完整操作。只接管本票已交付的操作，尚未移交的功能保留既有流程；全部票據完成後，規格內的正常受管理寫入均走同一工具。缺少實際平台或 Agent 證據時明列未確認，不把離線產物通過當作行為已通過。
