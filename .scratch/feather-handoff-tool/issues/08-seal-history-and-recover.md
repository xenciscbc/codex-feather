# 08: 封存歷史與恢復中斷操作

Type: task
Status: resolved
Blocked by: 05, 06
Parent: [Feather 交接工具規格](../spec.md)

**What to build:** 使用者可把明確選定的完整歷史搬入封存，失敗後依同一目的資料重試；歸檔尚未收尾時延後封存，避免之後重複追加。

**涵蓋使用者故事：** 35–38、42。

- [x] 只在使用者明確選取時封存，保留完成身份、完整正文與順序，不自動依大小或年齡封存。
- [x] 首次封存與封存重試都檢查直接工作檔的名稱、狀態及完成時間；相同完成身份仍有原交接時延後整次封存並保留全部檔案。
- [x] 相同身份正文不同時回報衝突；無法可靠排除相關未收尾工作的檔案問題需說明並延後，同名但不同完成時間不因此阻擋。
- [x] 先完整保存與驗證目的資料，再重新核對來源並移除相同選定紀錄；未選定歷史、工作檔與其他封存保持不變。
- [x] 目的檔已有不同內容時保留衝突；已有完全相同的重試資料時重用，不覆蓋或重複追加。
- [x] 中斷保留可恢復副本並回報目的位置，重試只處理原選取且仍相符的來源紀錄；讀回驗證兩側狀態後才回報完成。
- [x] 共同歷史仍由單一協調寫入者操作，沿用內容版本與實際路徑範圍檢查，不加入鎖。
- [x] 同步 skill 封存流程；透過公開入口驗收正常封存、目的衝突、保存後來源移除失敗／重試，以及完成原檔尚在便封存的連續情境。驗收操作順序及資料保留，區分離線與實際 Agent 證據。

**交付邊界：** 本票包含對應的工具行為、skill／使用指引及公開入口驗收；不以只建立內部模組或手寫預期產物代替完整操作。只接管本票已交付的操作，尚未移交的功能保留既有流程；全部票據完成後，規格內的正常受管理寫入均走同一工具。缺少實際平台或 Agent 證據時明列未確認，不把離線產物通過當作行為已通過。
