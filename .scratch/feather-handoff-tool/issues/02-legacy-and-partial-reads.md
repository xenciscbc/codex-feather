# 02: 查閱舊交接與處理不完整清單

Type: task
Status: resolved
Blocked by: 01
Parent: [Feather 交接工具規格](../spec.md)

**What to build:** 使用者可以查閱舊格式交接；部分檔案損壞、無法讀取或讀取中變動時，仍取得可讀工作與清楚的完整性說明，避免錯誤接續。

**涵蓋使用者故事：** 10、17–22、26、42。

- [x] 舊格式保留可辨識資訊，長進度節錄有明確標示；未知或缺漏資訊不憑空補齊。
- [x] 不可讀、解碼失敗、重複必填欄位及無法辨識的結構分別列出問題檔案與原因，不默默漏掉。
- [x] 回傳可讀結果並標示清單不完整；區分完整無匹配、來源不存在及部分失敗。
- [x] 觀察到讀取期間檔案新增、移除或內容變動時可有界重試，無法完成核對則說明限制；不保證同一瞬間快照。
- [x] 同名不同檔案仍分列；檔案消失不被解讀為工作完成。
- [x] skill 不依不完整清單宣稱無待辦或自動選定唯一工作；接續指定工作仍讀完整原檔並核對相關專案來源。
- [x] 查詢不改寫或修復舊檔、不改 Git 規則、不執行工作；修復留待有更新授權的操作。
- [x] 沿用公開工具入口與隔離 trial，驗收混合新舊資料、長內容、不可讀檔案、格式損壞及讀取變動；核對操作前後資料未變，行為證據與產物證據分開記錄。

**交付邊界：** 本票包含對應的工具行為、skill／使用指引及公開入口驗收；不以只建立內部模組或手寫預期產物代替完整操作。只接管本票已交付的操作，尚未移交的功能保留既有流程；全部票據完成後，規格內的正常受管理寫入均走同一工具。缺少實際平台或 Agent 證據時明列未確認，不把離線產物通過當作行為已通過。


## Answer

舊格式與格式歧義回傳 partial，保留可讀項目並標示問題；長進度明示節錄，指定讀取保留全文。清單重核檔名集合及讀取版本，發現變動標示不完整。公開工具 4 項測試與型別檢查通過；未把變動偵測當成鎖定或原子快照。

整體驗收：[工具驗收記錄](../../../docs/handoff-tool-validation.md)。Windows 全套 145 項通過（略過 2）；WSL 新增 31 項通過（略過 3 項 Windows 分享限制測試）。Agent 行為與未確認項目分開記錄，不將離線通過視為全部原生行為已驗證。
