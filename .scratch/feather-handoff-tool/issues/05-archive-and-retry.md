# 05: 完成歸檔與失敗重試

Type: task
Status: resolved
Blocked by: 04
Parent: [Feather 交接工具規格](../spec.md)

**What to build:** 工作完成後，工具自動保存完成版並歸入共同歷史；中途失敗保留完成待歸檔項目，重試可安全收尾且不重複追加。

**涵蓋使用者故事：** 7、28–32、38、42。

- [x] Agent 判斷整項工作完成後，正常完成流程透過工具保存完成版並接續歸檔，無需另一個額外歸檔指令。
- [x] 完整歷史保存並讀回驗證後，重讀並核對相符原交接才移除；新歷史可建立，既有歷史及其他工作完整保留。
- [x] 沿用工作名稱及完成時間作為重試身份；完成時間不因重試重設，同身份正文相同不再次追加。
- [x] 同身份正文不同、不可辨識歷史、非檔案目標或版本變動時保留資料並回報，不強行覆寫。
- [x] 歷史保存失敗或原檔移除失敗時保留可恢復副本與實際狀態；原檔仍在時清單顯示完成待歸檔。
- [x] 失敗後重試能從殘存資料收尾，成功後原交接不再出現在預設清單；不同完成身份的同名歷史仍完整存在。
- [x] 共同歷史由單一協調寫入者依序操作；已知其他 session 正在寫入時延後共同歷史變更，保留完成交接。
- [x] 同步完成與重試的 skill 流程；沿用公開操作與隔離故障先例，驗收首次、追加、同名、重試、正文衝突及兩種失敗。驗收需核對操作順序；僅產物正確不代表順序已證明。

**交付邊界：** 本票包含對應的工具行為、skill／使用指引及公開入口驗收；不以只建立內部模組或手寫預期產物代替完整操作。只接管本票已交付的操作，尚未移交的功能保留既有流程；全部票據完成後，規格內的正常受管理寫入均走同一工具。缺少實際平台或 Agent 證據時明列未確認，不把離線產物通過當作行為已通過。


## Answer

完成版保存後自動呼叫歸檔；公開 archive 重試沿用原身份。公開測試目前 5 項通過，更多故障證據於整體驗收補列。

整體驗收：[工具驗收記錄](../../../docs/handoff-tool-validation.md)。Windows 全套 145 項通過（略過 2）；WSL 新增 31 項通過（略過 3 項 Windows 分享限制測試）。Agent 行為與未確認項目分開記錄，不將離線通過視為全部原生行為已驗證。
