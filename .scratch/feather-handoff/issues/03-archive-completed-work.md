# 03: 完成工作歸入共同歷史

Type: task
Blocked by: 01
Status: resolved

**What to build:** 已啟用交接的工作完成後，將最後紀錄追加到共同交接歷史，確認保存成功才移除原交接檔，讓未完成工作與歷史分開。失敗與重試保留可恢復內容，不遺失或重複歸檔。依賴 01 的交接更新流程與隔離驗收能力。

- [x] 工作完成時整理最後交接內容，包含完成狀態、最後進度及驗證結果，不捏造完成或通過的證據。
- [x] 所有完成工作追加到規格約定的一份共同歷史，以工作名稱與完成時間分隔；保留既有歷史，不改成每項工作一份歷史檔。
- [x] 確認該次完成內容已成功保存後，才移除原交接檔；未完成工作的交接檔與無關內容不受影響。
- [x] 寫入失敗時保留原交接檔與可恢復資料，回報實際狀態，不宣稱完成歸檔；歷史寫入成功但原檔移除失敗時也如實回報。
- [x] 中斷後重試先辨識該次內容是否已保存，避免重複追加或誤刪；同名工作在不同完成時間的紀錄保持可辨識。
- [x] 歷史追加若發現其他 session 的變更，先核對並保留有效內容，不能以舊副本覆蓋新歷史；不承諾完整競態或交易保證。
- [x] 完成後不再保留該工作於預設待接續資料中；尚未歸檔成功但已標完成的原檔保持可恢復，不改回未完成來掩蓋失敗。
- [x] 未收到使用者清除要求時保留歷史，不因日期、容量或完成新工作而自動刪除、輪替或拆分。
- [x] 沿用隔離情境驗收首次歸檔、追加既有歷史、同名不同完成時間、歷史写入失敗、移除原檔失敗及中斷重試，確認既有資料與未完成工作完整。
- [x] 核對保存與移除的實際先後操作證據；最終檔案結果不單獨證明「先確認保存再移除」。提供使用說明與驗收紀錄，未具備證據的部分標為未確認。

## Comments

規格使用者故事覆蓋：22–24、27、29。歸檔可由完成一項已有交接的工作直接示範，因此不依賴 02 的新 session 接續功能；明確查閱與清除由 04 交付。

## Answer

完成歸檔規則及隔離驗收已交付，十三項累計離線測試通過。獨立 Agent 實際驗證正常追加、同名不同完成時間保留、已保存紀錄重試不重複追加、歷史位置受阻保留原檔，以及用 Windows 檔案共享鎖製造「已保存但無法移除」並保留兩份可恢復內容；外部測試鎖已釋放。核對了實際讀回與移除順序，來源與其他工作保持不變。

審查後補測：新增歷史尚不存在的首次歸檔情境，離線測試及獨立 Agent 的建立、完整讀回與移除順序驗證均通過。最終完整工作區 36 項、獨立提交版本 31 項測試通過。
