# 02: 新 session 讀取與接續工作

Type: task
Blocked by: 01
Status: resolved

**What to build:** 使用者在同一專案、同一目錄的新 session 要求讀取或接續時，找到正確交接檔並得到合乎意圖的結果：讀取只回報，接續才核對現況並繼續執行。依賴 01 的可呼叫 skill、交接資料契約與隔離驗收入口。

- [x] 新 session 未要求交接或接續時不自動讀取；明確呼叫後能使用先前 session 留下的同一份工作紀錄，不依賴舊對話仍在上下文。
- [x] 依使用者指定或訊息可辨識的工作名称選取；未指名且只有一項未完成工作時直接選取。
- [x] 有多項未完成工作且無法辨識時列出工作名稱詢問，不單憑更新時間猜測；沒有可用紀錄或指定工作不存在時如實說明，不虛構進度。
- [x] 「讀取交接／上次做到哪」只報告紀錄狀態，不執行下一步，不因查閱改寫工作內容。
- [x] 「接續上次／繼續做」先核對相關檔案與目前狀態，再執行已授權的下一步；過時資訊修正為實際狀態，交接內容不擴張授權。
- [x] 接續後沿用 01 的更新規則，讓重要進展或阻礙反映在原交接檔中。
- [x] 共同歷史與已完成紀錄不列入預設待接續候選；一般接續不讀取共同歷史。可用預置歷史素材驗證，不依賴 03 已實作歸檔。
- [x] 沿用隔離情境，涵蓋指名、唯一、多項、缺失、過時紀錄及同目錄跨 session 接續；使用可辨識副作用的下一步，驗證讀取沒有執行、接續有核對並執行。
- [x] 同時檢查回覆、交接資料與實際操作證據，核對未自動讀歷史、未讀取後擅自執行；不以檔案雜湊相同代替操作證據。
- [x] 更新使用說明與驗收紀錄，保留真實模型測試的明確啟用要求，缺少跨 session 原生證據不能宣稱完整通過。

## Comments

規格使用者故事覆蓋：01、03、15–21、25。與 03 沒有功能依賴；若修改同一份 skill 或驗收工具，實作時協調檔案所有權即可，不增設虛假的阻擋邊。

## Answer

已交付讀取／接續的選擇、現況核對與更新流程；八項累計離線測試通過。獨立 Agent 實際驗證指名查閱不執行、多项先詢問、只有歷史時不讀歷史，以及將過時 /legacy 核對為 /ready 後寫入指定成果並保留 timeout 阻礙。另以全新無對話繼承的 Agent 接續先前 Agent 建立的交接檔，成功辨識唯一工作、核對來源並更新後暫停。來源與共同歷史均保持不變，原生 CLI 自動發現通道未另外執行。
