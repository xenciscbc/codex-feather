# 04: 按要求查閱與清除交接歷史

Type: task
Blocked by: 03
Status: resolved

**What to build:** 使用者明確要求時查閱共同交接歷史，或清除其指定的歷史範圍；保留未指定紀錄與未完成工作。依賴 03 的共同歷史格式與歸檔行為，完成從工作歸檔到按需回顧及清理的流程。

- [x] 明確要求查閱歷史時才讀取並回報；單純查閱不改寫歷史、不啟動其中已完成工作的下一步。
- [x] 支援查閱指定工作或使用者要求的歷史範圍；工作名稱與完成時間可區分同名紀錄，沒有歷史或沒有符合紀錄時如實說明。
- [x] 未明確要求清除時保留全部歷史，不自動因時間或檔案大小清理。
- [x] 明確要求清除全部歷史時只清除共同歷史範圍；要求清除部分時只移除可辨識的指定紀錄，保留其他歷史與未完成交接檔。
- [x] 清除範圍不明或同名多筆無法判斷時先詢問，不猜測刪除對象；已有明確範圍與授權時不重複要求確認。
- [x] 清除前若發現共同歷史被他處修改，先核對最新內容；失敗時回報實際保存狀態，不將部分或未完成操作宣稱為成功。
- [x] 沿用隔離情境，從 03 產生的歷史驗收指定查閱、無歷史、沒有符合紀錄、同名歧義、部分清除、全部清除與清除失敗，核對未指定資料完整。
- [x] 透過回覆、產物及原生操作證據確認查閱沒有執行或清除，明確清除只影響指定範圍；驗收不依賴提示詞的特定措辭。
- [x] 更新歷史查閱與清除使用說明、可重現驗收方式及結果；維持專案 Agent 指令入口不變，保留真實模型驗收明確啟用與缺失證據標記。

## Comments

規格使用者故事覆蓋：26–29。一般接續排除歷史由 02 負責；本票的明確歷史操作只依賴 03，不額外依賴 02。

## Answer

已交付歷史查閱、明確範圍清除與失敗回報。十九項累計交接離線測試通過；獨立 Agent 實際驗證指定查閱、無歷史、沒有匹配紀錄、同名歧義先詢問、部分清除保留較早同名紀錄、全部清除保留未完成工作，以及 Windows 檔案鎖造成清除失敗後逐字保留原歷史。外部測試鎖已釋放。另補強共用验收工具，保留既有情境對 Git metadata 副作用的檢查。
