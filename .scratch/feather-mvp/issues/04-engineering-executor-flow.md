# 04: executor 工程實作流程

**What to build:** 主 Agent 將需要局部工程判斷的修改交給 executor，由其完成範圍內的實作與必要檢查，再由主 Agent 整合成果。

**Blocked by:** 01 — 隔離環境與 scout 查找流程。

**Status:** ready-for-human

- [x] 新增 executor 模板，預期使用 gpt-5.6-sol／medium，沿用隔離入口。
- [x] 任務素材需要局部設計判斷且有明確可檢查需求，分工規則能將其與完整規格的機械修改區分。
- [x] 派工明確交代修改範圍與完成條件，主 Agent 和其他子 Agent 不同時寫入該範圍。
- [ ] 以實際成果行為及適當測試驗證需求，不以輸出格式或提示詞文字作為正確性證據。
- [ ] 修改不超出指派範圍；跨範圍決策或規格不明交回主 Agent 處理。
- [ ] 主 Agent 收回並整合結果，核對實際模型／reasoning，簡短回報必要判斷及未確認事項。
- [x] 共用規則的修改由主 Agent 協調，保留已完成的查找流程。
