# 02: analyst 唯讀分析流程

**What to build:** 使用者提出原始碼或邏輯性文件分析時，主 Agent 能選擇 analyst，取得證據、推論及建議，再自行決定後續是否修改。

**Blocked by:** 01 — 隔離環境與 scout 查找流程。

**Status:** ready-for-human

- [x] 新增 analyst 模板，預期使用 gpt-5.6-sol／medium，保持唯讀，沿用已驗證的隔離入口。
- [x] 分工规则明確將因果推導、矛盾辨識與影響分析歸為分析，不能僅因唯讀而派給 scout。
- [ ] 分別以原始碼與邏輯文件素材驗證已知的邏輯或矛盾，結果有可核對證據，區分事實與推論。
- [ ] 分析過程沒有修改副作用，analyst 將建議交回主 Agent；主 Agent 明確決定後續行動。
- [x] 回報簡單扼要，只保留必要證據、不確定性與待決事項。
- [ ] 核對實際模型與 reasoning；缺失證據標記未確認，不以模板或自述代替。
- [x] 共用規則的調整保留 scout 行為；共享修改範圍由主 Agent 協調，避免其他角色任務同時覆寫。
