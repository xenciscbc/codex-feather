# 05: 主 Agent 直接處理與通用委派

**What to build:** 主 Agent 可直接完成不值得拆分的任務，也可將不屬於固定角色的獨立工作交給通用子 Agent，保留使用者的主模型能力。

**Blocked by:** 01 — 隔離環境與 scout 查找流程。

**Status:** ready-for-human

- [ ] 查證通用子 Agent 的原生呼叫方式與模型／reasoning 繼承行為，記錄來源及執行證據。
- [ ] 分別驗證小任務與需要持續整合全局資訊的推理情境，由主 Agent 直接完成，不強制委派。
- [ ] 驗證明確且獨立、又不屬於固定角色的任務可由通用子 Agent 處理，完成 brief 所指定的產出。
- [x] 不覆蓋主模型或 reasoning，不固定使用 Astra，不採用 Spark；通用子 Agent 預期繼承主 Agent 設定。
- [x] 缺乏實際繼承證據時標示未確認；不支援時明確回報差異，不靜默換用其他模型。
- [x] 主 Agent 對回收成果負責整合；無委派時簡述直接完成，有委派時提供簡短分工及證據狀態。
- [x] 沿用隔離入口及真實測試需明確啟用的界線；共用規則修改由主 Agent 協調。
