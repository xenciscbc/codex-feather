# 由工具管理交接檔，清單即時產生

交接清單的目的在於減少 Agent 閱讀全文的成本；使用者接受程式逐檔掃描，因此第一版從交接 Markdown 即時產生清單，不維護持久索引。Agent 負責摘要、工作判斷與授權範圍，Python 工具統一處理格式驗證及檔案讀寫，包含歸檔、重試、清除與封存，以避免兩套寫入路徑的規則分歧。

使用者接受 Python 環境需求，缺少時先詢問是否協助安裝；第一版保留人工編輯能力，以單一寫入者協調及版本檢查處理衝突，不加入鎖定機制，也不保證未協調的跨 session 並行寫入安全。整體規格已確認並發布至本機議題追蹤器，詳見 [交接工具規劃](../handoff-tool-plan.md)；八項操作已實作，驗收證據與限制見 [工具驗收](../handoff-tool-validation.md)。
